베타 핵심 기능 TOP 6

진짜 필요한 것만, 실행 가능한 수준으로.

1

모집글 등록

주최자가 5분 안에 게임 올리게.

  • 필수: 날짜/시간/장소/인원/레벨/비용
  • 선택: 메모/규칙 + 사진 1장
2

게임 탐색 & 필터

게임을 “찾는 시간” 자체를 줄이기.

  • 필터: 날짜/지역/레벨
  • 리스트 카드 UI
  • 지도뷰는 추후
3

참여 신청 1클릭

댓글/DM 절차를 한 번에.

  • 참여하기 → 주최자 알림
  • 승인제 + 자동확정 옵션
4

실시간 인원 현황

“지금 몇 명 모였지?”를 즉시.

  • 3/10 모집 표시
  • 마감 자동 처리
5

프로필(신뢰도)

평점 없이도 최소 신뢰 확보.

  • 닉네임/레벨/소개 50자
  • 참여/주최 횟수 표시
6

알림(푸시/인앱)

확정/취소/리마인더는 놓치면 끝.

  • 신청/승인/거절 알림
  • D-1 리마인더
베타에서 일부러 뺀 것
범위가 흔들리면 MVP가 망가져서, 지금은 안 함.
시설 예약/결제 채팅 평점/별점 참가비: 현장 수납

동작 방식 (핵심 플로우)

모집 → 신청 → 승인 → 알림. 이게 전부.

1) 주최자: 게임 등록
템플릿으로 날짜/장소/인원/레벨/비용만 채우면 끝.
Create Game · 사진 1장 옵션
2) 게스트: 필터 + 1클릭 신청
단톡방/카페 탐색 대신, 조건으로 리스트만 보면 됨.
Filter · 날짜/지역/레벨
3) 승인/확정 + 알림
주최자 승인제(또는 자동확정)로 상태가 명확해짐.
Approve · D-1 리마인더
운영 포인트
  • 첫 주 게임 10개는 무조건 확보(운영이 직접 열어도 됨)
  • 노쇼는 “리마인더 + 신고 + 누적 정지”로 최소 장치
  • 허위 모집은 “사전검수 없음 + 신고 기반”으로 속도 우선

화면 구성(최소)

소개용으로는 여기까지 보여주면 설득 충분.

1

로그인/회원가입

소셜 로그인 + 닉네임/레벨/지역

2

홈(탐색)

필터(날짜/지역/레벨) + 게임 카드 리스트

3

게임 상세

정보/인원현황 + 참여하기 + 댓글 Q&A

4

게임 만들기

모집글 폼 + 사진 1장 옵션

5

내 게임 관리

신청자 승인/거절 + 인원 관리

6

내 참여 목록

대기/확정 + D-day 표시 + 이력

여기 교체하면 “실제 제품 느낌” 바로 남
1) 실제 앱 스크린샷 4~6장 넣기
2) 피그마 프레임 이미지로 “홈/상세/만들기/관리”만 넣기

FAQ

소개 페이지에서 미리 컷할 질문들.

시설 예약도 되나요? 베타 범위
아니. 베타는 픽업 모집/참여에만 집중. 예약/결제는 다음 단계.
채팅은 왜 없어요? 대체
베타는 댓글 Q&A로 최소 소통만. 채팅은 운영/악용/CS 비용 커져서 뒤로 뺌.
노쇼는 어떻게 막아요? 신뢰
D-1 리마인더 + 노쇼 신고 + 누적 정지(2회)로 최소 장치부터. 결제는 추후.
레벨은 누가 판단해요? 초/중/상
베타는 자가 선택. 대신 주최자가 “레벨 제한”을 명확히 걸 수 있게 설계.
