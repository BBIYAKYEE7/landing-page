베타 목표(측정 가능)

한 문장: 주최자와 게스트를 연결해서
주 1회 이상 / 매칭 성공률 70%+ 달성.

성사율 70%+ 게시된 게임 중, 필요 인원 충원 완료 비율
주최자 주 1회+ 주최자 1명당 평균 모집글 게시
게스트 월 2회+ 게스트 1명당 참여 신청/참여 빈도
목표 유저 주최자 30+ / 게스트 200+ (12주)
시드 전략: 론칭 첫 주 게임 10개는 무조건 깔고 간다.

지금 문제는 딱 이거

모집은 흩어져 있고, 관리는 수동이고, 신뢰는 애매함.

베타 포커스 · 모집/참여/관리

주최자 니즈 / 불편

  • 빠르게 인원 충원 → 단톡/인스타/카페 흩어짐, 응답 느림
  • 노쇼 방지 → “간다” 해놓고 당일 잠수, 게임 무산
  • 실력/성향 맞는 사람 선별 → 정보 부족해서 뽑기
  • 모집 공지 반복 피로 → 매번 타이핑, 템플릿 없음
  • 확정자 관리 → 누가 확정인지 수동 체크로 헷갈림

게스트 니즈 / 불편

  • 오늘/이번주 뛸 게임 찾기 → 여러 채널 뒤지느라 시간 낭비
  • 레벨/일정 맞는 게임 필터링 → 초/중/상 모르면 가서 눈치
  • 참여 신청 간편화 → 댓글→DM→연락처… 절차 귀찮음
  • 게임 전 정보 확인 → 주소/주차/준비물 매번 질문
  • 신뢰 가능한 주최자 → “이거 진짜 열리나?” 불안
시설 예약/결제 없음 채팅 없음(댓글로 대체) 평점/별점 없음(악용 우려)

해결 방식: “모집 → 신청 → 승인 → 알림”을 한 곳에

단톡방 대신, 게임 단위로 상태가 굴러가게 만들기.

핵심 사용자 경험(베타)

  1. 주최자는 5분 안에 모집글 등록(템플릿화)
  2. 게스트는 조건 필터로 게임 찾고 1클릭 신청
  3. 주최자 승인제로 확정/거절이 즉시 반영
  4. 인원 현황(3/10)이 실시간으로 보이고, 마감 자동 처리
  5. 중요 이벤트는 푸시/인앱 알림으로 놓치지 않게

베타 성공 정의

“빈 앱” 느낌만 없애면, 베타는 굴러가기 시작함.

  • 첫 주 게임 최소 10개 보장 (운영이 직접 열어도 됨)
  • 게임 성사율 70%+ 달성
  • 오프라인 커뮤니티에서 “일단 SITE 켜봄” 습관
  • 주최자 피드백: “단톡보다 편하다”
빈 앱 느낌 방지 운영 주최 게임 운영 시드 주최자 30명 확보

베타 핵심 기능 TOP 6

“실행 가능” 수준으로 최소 구현 범위까지.

1

픽업 게임 모집글 등록

주최자가 5분 안에 게임 올리는 게 목표.

  • 필수: 날짜/시간/장소/인원/레벨/비용
  • 선택: 메모/규칙 + 사진 1장
2

게임 탐색 & 필터

게스트가 조건 맞는 게임만 빠르게 보게.

  • 필터: 날짜/지역/레벨
  • 리스트 + 카드형 UI
  • 지도뷰는 베타 제외
3

참여 신청 (1클릭)

댓글/DM 왔다갔다 없애기.

  • 참여하기 버튼 → 주최자 알림
  • 주최자 승인제 + 자동확정 옵션
4

실시간 인원 현황

“3/10 모집 완료” 상태가 핵심.

  • 모집글에 현황 표시
  • 마감 자동 “모집 마감”
5

주최자/게스트 프로필

신뢰도 + 레벨 감 잡기.

  • 닉네임/사진(선택)/소개 50자
  • 레벨(초/중/상) 자가 선택
  • 참여/주최 이력 횟수 표시
6

알림(푸시/인앱)

확정/취소/리마인더 놓치면 끝.

  • 신청 → 주최자 알림
  • 승인/거절 → 게스트 알림
  • D-1 리마인더

베타에서 뺀 기능(명확히)

시설 예약/결제 채팅(댓글로 대체) 평점/별점(악용 우려) 참가비: 현장 수납

화면 구성(최소 10개)

이대로 만들면 MVP 플로우가 끊기지 않음.

1

로그인/회원가입

소셜 로그인(카카오/구글) + 닉네임/레벨/지역 입력

2

홈(게임 탐색)

날짜/지역/레벨 필터 + 카드 리스트 + “게임 만들기”

3

게임 상세

정보/인원현황 + 참여하기 + 주최자 미리보기 + 댓글

4

게임 만들기

폼(날짜/시간/장소/인원/레벨/비용/메모) + 사진1장

5

내 게임 관리

내가 만든 게임 목록 + 신청자 승인/거절

6

내 참여 목록

신청 대기/확정(D-day)/과거 이력

7

프로필

닉네임/사진/레벨/소개 + 참여/주최 횟수 + 설정

8

알림

신청/승인/거절 + D-1 리마인더

9

설정

알림 설정/회원 탈퇴/약관/개인정보처리방침

10

댓글/Q&A

게임 상세 내 댓글로 간단 소통(주차/준비물 등)

플로우(텍스트)

[유저 진입] 로그인/회원가입 → 프로필 입력 → 홈 [게스트] 홈(필터) → 게임 상세 → 참여하기 → 내 참여 목록(대기) → 주최자 승인 알림 → 내 참여 목록(확정) [주최자] 홈 → 게임 만들기 → 등록 → 내 게임 관리 → 신청 알림 → 승인/거절

운영 정책(베타 초안)

신뢰도/노쇼/신고를 “최소 규칙”으로 잡아두기.

모집글 검수

  • 추천(베타 초기): 사전 검수 없음 → 신고 기반 사후 조치
  • 허위/욕설/광고성 → 삭제 + 경고
  • 향후: 주최자 인증/첫 게임 검수 옵션
빠른 등록 우선 신뢰 타격은 빠르게 대응

신뢰도 / 노쇼 방지

  • 프로필 필수: 닉네임 + 레벨(초/중/상) / 사진은 선택
  • 이력 표시: 참여 00회 / 주최 00회 (별점 없음)
  • D-1 리마인더 푸시 필수
  • 노쇼 2회 누적 → 계정 일시 정지(수동 검토)
  • 게임 종료 후 “진행 완료” 체크(주최자)

참가비/취소 정책(베타)

  • 참가비는 현장 수납 (앱 결제 없음)
  • 24시간 전: 자유 취소
  • 24시간 이내: 주최자 알림 + 프로필 “최근 취소”(1주 유지)
  • 당일 노쇼: 주최자 신고 → 노쇼 1회 누적
결제는 추후 도입 노쇼 대응 장치만 확보

베타 론칭 체크리스트

  • 핵심 기능 6개 QA 완료
  • 시드 유저: 주최자 30+ / 게스트 100+ 사전 확보
  • 첫 주 게임 10개 보장(운영 주최 포함)
  • 신고/문의 24시간 내 대응 채널 공지
  • 약관/개인정보처리방침 앱/웹 게시

FAQ

외부에 던졌을 때 제일 많이 나올 질문들.

시설 예약도 되나요? 베타 범위
베타에서는 시설 예약/결제는 안 해. 지금은 “픽업 게임 모집/참여”에만 집중하고, 예약은 다음 단계에서 붙일 계획이야.
채팅은 없나요? 대체 수단
베타에서는 채팅 없음. 대신 게임 상세에 댓글/Q&A로 “주차/준비물/주소” 같은 것만 가볍게 처리하게 설계했어.
노쇼는 어떻게 막아요? 신뢰도
D-1 리마인더 + 노쇼 신고 + 2회 누적 정지(수동 검토)로 최소 장치부터 시작. 결제(선결제)는 베타에서 데이터 보고 다음 단계로.
레벨은 누가 판단하나요? 초/중/상
베타는 자가 선택이 기본. 대신 주최자가 “실력 제한”을 명확히 걸 수 있게 하고, 이후에 피드백 기반으로 개선해.
참가비는 앱에서 결제하나요? 베타
현장 수납만. 모집글에 금액을 명시하고, 결제는 추후 도입 검토.
