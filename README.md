# U-TEED Landing Page

U-TEED 랜딩 페이지 프로젝트입니다. Next.js(App Router)와 TypeScript로 구성되어 있습니다.

## 링크

- 사이트: https://u-teed.co.kr/

## 개발/빌드

```bash
npm run dev
npm run build
npm run start
```

## 프로젝트 의뢰 이메일

의뢰 폼은 `taeho@u-teed.co.kr`을 수신자로 지정하고 입력 내용을 담은 이메일 초안을
이용자의 이메일 앱에서 엽니다. 이용자가 직접 내용을 확인하고 전송해야 합니다.
SMTP 비밀번호나 서버 측 이메일 발송 설정은 필요하지 않습니다.
첨부된 개인정보 처리방침 초안에는 현재 구현과 다른 운영 내용이 포함되어 있으므로
공개하기 전에 실제 처리 방식과 보유 기간을 확인해야 합니다.

## 구조

- `src/app`: App Router 페이지
- `src/components`: 공통 컴포넌트
- `src/types`: 타입 정의
